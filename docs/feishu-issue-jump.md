# 飞书任务跳转书签

## 书签作用

这是一个用于快速跳转到飞书项目任务详情页面的书签工具。通过输入飞书任务号，可以自动解析任务类型并打开对应的详情页面。

**功能特点：**

- 支持多种飞书任务类型的快速跳转
- 🚀 **智能剪贴板检测**：自动读取剪贴板，如有合法任务号则直接跳转
- 自动识别任务号格式并跳转到对应页面
- 智能输入处理：自动去除空格、大小写转换
- 配置化设计，易于扩展新的任务类型
- 友好的错误提示和使用指引
- 输入错误时自动重试，无需重新点击书签

**支持的任务类型：**

- `f-xxx`: 飞书议题 (issue) → 跳转到 `/issue/detail/`
- `g-xxx`: 飞书任务 (assignment) → 跳转到 `/assignment/detail/`
- `m-xxx`: 飞书需求 (story) → 跳转到 `/story/detail/`
- `s-xxx`: 飞书看板 (sprint) → 跳转到 `/s/detail/`

## 注意事项

1. **任务号格式要求**：按照 `字母-数字` 的格式输入，如 `f-123`、`g-456` 等（支持大小写，会自动处理前后空格）
2. **网络要求**：需要能够访问飞书项目平台 (project.feishu.cn)
3. **权限要求**：需要有对应项目的访问权限，否则可能无法查看任务详情
4. **浏览器兼容性**：支持所有现代浏览器，需要启用 JavaScript
5. **剪贴板权限**：首次使用时可能需要授权剪贴板读取权限，拒绝后仍可正常使用手动输入
6. **使用场景**：适用于经常需要在飞书项目间快速跳转的开发和项目管理场景
7. **最佳体验**：复制任务号后直接点击书签，无需手动输入即可跳转
