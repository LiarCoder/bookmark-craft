# 显示星号密码

## 书签作用

这是一个用于显示网页中星号密码的书签工具。通过将密码输入框的类型从 `password` 临时切换为 `text`，让用户能够看到实际输入的密码内容，方便在忘记密码时进行确认。

**功能特点：**

- 🔍 **智能识别**：自动检测页面中所有密码输入框
- 🔄 **类型切换**：将密码框从 `password` 类型切换为 `text` 类型
- 💾 **状态保存**：使用 `data-origin-type` 属性保存原始类型
- 🔒 **安全恢复**：支持将已切换的密码框恢复为原始状态
- ⚡ **即时生效**：无需刷新页面，点击即可看到密码内容

**适用场景：**

- 🔑 **密码确认**：忘记已输入密码时快速查看确认
- 🧪 **开发调试**：前端开发时测试密码输入框功能
- 📱 **移动设备**：在手机等小屏设备上更容易确认密码
- 🎯 **用户体验**：帮助用户避免密码输入错误
- 🔍 **安全检查**：验证密码是否正确输入

## 注意事项

1. **浏览器兼容性**：支持所有现代浏览器，需要启用 JavaScript
2. **使用限制**：仅切换当前页面已有密码输入框，不会读取、保存或发送密码
3. **安全说明**：密码会直接显示在屏幕上，只应在可信环境中使用；再次点击可恢复隐藏状态
