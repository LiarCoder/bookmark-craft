# 测试示例书签

## 书签作用

这是一个用于演示和测试书签功能的示例脚本。主要用于验证构建系统的代码压缩和优化功能，同时展示基本的网站检测能力。

**功能特点：**

- 检测当前访问的网站类型
- 针对不同网站显示相应的提示信息
- 包含调试代码用于测试构建系统的代码清理功能

**支持检测的网站：**

- GitHub.com - 显示 GitHub 专属提示
- StackOverflow.com - 显示 Stack Overflow 专属提示
- 其他网站 - 显示通用提示信息

## 注意事项

1. **用途说明**：这是一个测试用的示例书签，主要用于开发和测试环境
2. **调试代码**：包含 `console.log` 和 `debugger` 语句，在生产构建时会被自动移除
3. **功能限制**：仅支持检测 GitHub 和 Stack Overflow 两个特定网站
4. **开发用途**：
   - 验证 Terser 代码压缩功能
   - 测试调试代码清理机制
   - 作为其他书签开发的参考模板
5. **不建议生产使用**：此书签仅用于开发测试，不建议在实际工作环境中使用
