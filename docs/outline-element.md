# 元素轮廓显示书签

## 书签作用

这是一个用于调试和分析网页布局的开发工具书签。通过为页面上的所有元素添加彩色轮廓线，帮助开发者可视化页面结构和元素边界。

**功能特点：**

- 🎨 **一键切换**：点击书签即可开启/关闭轮廓显示
- 🌈 **随机彩色轮廓**：每个元素显示不同颜色的轮廓线，便于区分
- 🔄 **状态记忆**：自动记住当前显示状态，支持反复切换
- ⚡ **即时生效**：无需刷新页面，立即显示效果
- 🎯 **全元素覆盖**：为页面上所有 DOM 元素添加轮廓

**适用场景：**

- 前端开发调试布局问题
- 分析网页结构和元素层级
- 检查元素边界和间距
- 学习和研究网页设计
- CSS 布局问题排查

## 注意事项

1. **性能影响**：在元素数量极多的页面上可能会有轻微的性能影响
2. **样式优先级**：轮廓线通过 `style.outline` 设置，优先级较高
3. **浏览器兼容性**：支持所有现代浏览器，需要启用 JavaScript
4. **临时效果**：刷新页面后轮廓线会消失，需要重新点击书签
5. **开发用途**：主要用于开发和调试，不建议在生产环境长期使用
6. **颜色算法**：使用随机数生成 16 进制颜色值，每次点击颜色会重新生成
7. **全局状态**：使用全局变量 `hasOutline` 追踪当前状态
